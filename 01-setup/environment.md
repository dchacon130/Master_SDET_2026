## Tool Purpose in QA Engineering
* **Git:** Evita la pérdida de código de automatización y permite el trabajo colaborativo mediante control de versiones, ramas y revisiones de código (*Pull Requests*).
* **Node.js:** Proporciona el entorno de ejecución (*runtime*) necesario para interpretar y correr frameworks modernos de pruebas en JavaScript/TypeScript (como Playwright).
* **npm:** Gestiona e instala de manera centralizada las librerías, dependencias y *runners* de pruebas que el proyecto necesita para ejecutarse.
* **Python:** Permite escribir *scripts* auxiliares rápidos para generación de datos de prueba, automatización de tareas secundarias o pruebas de API/seguridad.
* **GitHub CLI (** **gh** **):** Agiliza el flujo de trabajo al permitir gestionar repositorios, crear *Pull Requests* y monitorear pipelines de CI/CD directamente desde la terminal sin cambiar de contexto.
